# Proyecto Emasivo Daño a flota 

Un proyecto para gestionar el daño a flota en Emasivo By Cristian

# To Run project Now

First run pip install -r requirements.txt

1. activar el entorno
.\venv\Scripts\Activate.ps1 // powershell
.\venv\Scripts\Activate // Win CMD
2. cd backend folder
3. python backend_interfaz.py
4. Load web browser in http://localhost:5000 and be happy
